# Как запустить сверку

## Cloud.ru VMware

Рядом с `main.py` создайте файл `.env`. Для ссылки входа вида `https://vcd01-01.cloud.ru/tenant/my-tenant/` он выглядит так:

```dotenv
VCD_SITE=https://vcd01-01.cloud.ru
VCD_TENANT=my-tenant
VCD_API_TOKEN=вставьте_свой_токен
```

- **Адрес и тенант** возьмите из своей ссылки входа в VMware Cloud Director. В `VCD_SITE` укажите адрес до `/tenant/`, в `VCD_TENANT` — имя после него.
- **Токен** выпустите в VMware Cloud Director под учёткой с доступом на чтение пользователей и ролей. Откройте меню профиля → **User preferences → Access Tokens → NEW**, задайте имя, нажмите **CREATE** и скопируйте значение в `VCD_API_TOKEN`. [Инструкция Cloud.ru](https://cloud.ru/docs/vdc/ug/topics/basic-info/basic-info__api-token)
- **По желанию** добавьте в `.env` строку `USE_VMWARE_API=true`, чтобы включить VMware в режим «0 — всё». Для выгрузки только названий ролей без детализации прав добавьте `VCD_INCLUDE_RIGHTS=false`.

## Данные для сверки

| Что взять | Куда положить или что настроить |
|---|---|
| Актуальная штатка от кадров с колонкой «Ф.И.О.» или «ФИО» | `эксельки/штатка/` |
| Активные ГПХ из AD | Скрипт читает домен через PowerShell под текущей учёткой Windows. Ветки ГПХ задаются в `ad_export.py`. |
| Отчёт пользователей из 1С, лист «Лист_1», колонки «Пользователь» и «Недействителен» | `эксельки/1С/` |
| Выгрузки из Диадока и Сферы с ФИО и датой блокировки или признаком «Активен» соответственно | `эксельки/эдо_контур_диадок/` и `эксельки/эдо_сфера_курьер/` |

Для API ЭДО включите в `config.py` соответствующий флаг (`USE_DIADOC_API = True` или `USE_SFERA_API = True`). В `.env` укажите ключ Диадока `DIADOC_API_KEY` (при необходимости также `DIADOC_BOX_ID`) или данные учётки Сферы `SFERA_USERNAME` и `SFERA_PASSWORD`.

## Запуск и результат

В Windows откройте `cmd` в папке с `main.py`. При первом запуске установите зависимости, затем запустите скрипт:

```cmd
python -m pip install -r requirements.txt
python main.py
```

Для проверки VMware выберите **4**, затем **0** для всех категорий сотрудников. Откройте новый `вывод/результат_обработки_*.xlsx`. На листе **«Источники»** сравните число пользователей тенанта с **Administration → Users**. Кадровая сверка находится на листе **«Оценка доступа»**.
