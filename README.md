# Сверка пользователей 1С и ЭДО

Консольный скрипт для администратора. Проверяет, у кого остался активный доступ к 1С, Контур.Диадоку, Сфера Курьер или Cloud.ru VMware. Результат — Excel-отчёт для ручной проверки. Решение о блокировке принимает администратор.

[Настройка источников и запуск](how_to_use.md)

## Правила сверки

- Штатного сотрудника подтверждает присутствие в актуальном штатном расписании. Для исполнителя по ГПХ основанием служит включённая учётная запись в ветке ГПХ Active Directory. Расхождения между штаткой и AD выводятся отдельно в обе стороны.
- В 1С статус читается по заголовку «Недействителен». Значение «Нет» означает активную учётку, «Да» — неактивную. В Excel Диадока скрипт проверяет дату блокировки, в Сфере — поле «Активен».
- Активная учётка попадает на проверку доступа, когда оба кадровых источника проверены и человека нет ни в одном. Совпадение в доступном источнике подтверждает основание. Непрочитанный статус, неоднозначное ФИО или отсутствие необходимого источника дают результат «Недостаточно данных».
- ФИО сравниваются с учётом отчества, без различий в регистре, пробелах и буквах «е»/«ё». По фамилии и имени допускается однозначное совпадение, когда в одной из записей отсутствует отчество.

## Результат

Откройте новый файл `вывод/результат_обработки_*.xlsx`. Лист **«Источники»** показывает полноту загрузки. На листе **«Оценка доступа»** у каждой учётки указаны основание, статус и результат. При наличии записей создаются листы **«удалить из …»**, **«Недостаточно данных»** и листы возможных дублей. Журналы запуска находятся в `вывод/log/`.
